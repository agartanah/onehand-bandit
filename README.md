# 🎰 One-Hand Bandit

A simple browser-based slot machine built for fun.

## About

One-Hand Bandit is a small web project that recreates a classic slot machine experience. Spin the reels, try your luck, and see if you can hit a winning combination!

The game features three reels with four possible symbols:
- 🍒 Cherries
- 7️⃣ Sevens
- 🍋 Lemons
- **BAR**

## Features

- Three spinning reels.
- Four different symbols.
- Ability to lock selected reels for the next spin.
- A simple scoring system.
- A playful slot machine experience with no real money involved.

## How to Play

1. Open the game in your browser.
2. Press the **Spin** button to spin the reels.
3. Try to get matching symbols across all three reels.
4. Lock any reel to keep its current symbol during the next spin.
5. Experiment with different combinations and have fun!

## Disclaimer

This is a fun personal project. All scores are fictional, and no real money is involved. Please don't expect to get rich!
